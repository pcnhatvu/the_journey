- Complete Product CRUD API: create, read, update, and delete.

### 14:45 – 16:15 | Block 3: Complete Product CRUD API

#### Target Endpoints

| Method | Endpoint | Expected Result |
|---|---|---|
| `POST` | `/products` | Create a Product and return `201 Created` |
| `GET` | `/products` | Return the Product list |
| `GET` | `/products/{id}` | Return one Product or `404 Not Found` |
| `PUT` | `/products/{id}` | Update a Product or `404 Not Found` |
| `DELETE` | `/products/{id}` | Delete a Product and return `204 No Content` |

#### Implementation Principles

- The controller only accepts the request, calls the service, and converts the result into an HTTP response.
- The service coordinates the use case and business rules.
- The repository handles data access only.
- Use DTOs for requests and responses.
- Choose appropriate status codes and don't return a body for `204 No Content`.
